This is a First-Person Shooter prototype developed in Godot 4.6 as a practical extension of a critical review on game security and visual cheats.

Setup Instructions
Download and install Godot Engine version 4.6.

Extract the project files to a local directory.

Open Godot, click Import, and navigate to the project folder to select the project.godot file.

Once the editor loads, press F5 (or click the Play button in the top right) to launch the game.

Dependencies
Godot 4.6 (No external plugins, middleware, or third-party libraries are required to compile or run this project).

Controls
W, A, S, D: Move

Mouse: Look / Aim

Left Click: Shoot

R: Reload

Shift: Sprint

C / Ctrl: Crouch / Slide

Space: Jump

E: Interact

1, 2, 3, Mouse Wheel: Swap Weapons

WARNING: if unzipping and playing the project through the editor the animations of certain things seem to break.
